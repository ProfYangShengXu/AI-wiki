# 灰测清单(Gray-Test Checklist)

> 适用对象:灰测 Release(pre-release)的测试用户(建议 5 人)。
> 对应工作流:`.github/workflows/release.yml`;产物从 GitHub Releases 页面下载。
> 反馈渠道:GitHub Issues(https://github.com/ProfYangShengXu/AI-wiki/issues),附日志与截图。

## 0. 准备

- [ ] 获得 DeepSeek API Key(或由发布者提供测试 Key)
- [ ] Windows 测试者:下载 `client-windows.zip` 解压,双击 `studywiki_client.exe`(自动拉起内置后端;关闭窗口=最小化到托盘)
- [ ] Android 测试者:安装 `studywiki-client-debug.apk`(允许未知来源),与 Windows 服务同一局域网

## 1. 核心旅程(必测)

| # | 任务 | 预期 | 结果(✓/✗+备注) |
|---|---|---|---|
| 0 | 自启动/托盘 | 双击客户端:无需手动开后端即可用(观察托盘图标);关闭窗口后仍在托盘,托盘菜单"显示主窗口/退出";托盘退出后后端进程一并停止 | |
| 1 | 首次启动 | 出现灰屏引导;填错 Key 被拦截并提示错误码;填对 Key 后进入主界面 | |
| 2 | 导入文档 | 上传 Markdown/PDF/Word,进度条实时推进,可取消;完成后面板显示导入/跳过/失败数 | |
| 3 | 浏览知识库 | 卡片列表/搜索/分类过滤正常;知识图谱视图能打开、可拖拽、点击跳转 | |
| 4 | 提问(Ask) | 回答逐字流式输出,附知识来源 | |
| 5 | Agent 指令 | 说"创建一张XX卡片" → 工具步骤卡展示 → 卡片出现 | |
| 6 | 删除审批 | 说"删除XX卡片" → 弹出危险操作确认框;拒绝则不删、批准则删 | |
| 7 | Quiz | 出题 → 作答 → 评分带理由与参考答案;掌握度百分比更新 | |
| 8 | 组卷 | 多分类勾选生成综合试卷 | |
| 9 | 设置 | 查看设置页:API Key 只显示尾部掩码;改温度等配置立即生效 | |
| 10 | 备份恢复 | 设置页/API 创建备份 → 删除一张卡 → 恢复备份 → 卡片回来 | |
| 11 | Android 配对 | 服务端生成 6 位码 → App 输入配对 → 显示配对成功 | |
| 12 | 离线复习 | App 导出离线知识包 → 断网浏览卡片/做 Quiz → 回连后评分自动回传 | |
| 13 | 深色主题 | 切换深浅主题,重启后记忆生效 | |
| 14 | 错误恢复 | 断网提问 → 出现可读错误(含 SW-* 错误码),恢复网络后重试成功 | |

## 2. 观测指标(反馈时附上)

- 首次配置到可用的耗时(目标 ≤ 5 分钟)
- 各任务完成/失败/卡住情况
- 崩溃/闪退频率与复现步骤
- 大文件(>50 页 PDF)导入耗时与是否可取消
- 主观体验评分(SUS 10 题,目标 ≥ 80)

## 3. 已知限制(勿报)

- 客户端无自动更新;新灰测版需手动重新安装
- Windows 客户端与 exe 未签名(代码签名在正式版前补齐)
- Android 离线包为整包导出,暂无增量同步
- 局域网配对不加密传输数据(生产环境需自行组网安全)

## 4. 灰度通过标准

- 核心旅程 14 项 ≥ 90% 通过
- 无数据丢失类缺陷(备份/恢复、删除审批有效)
- 崩溃率 ≤ 0.5%(单测试者会话内)
- 反馈有效 issue ≥ 3 条(正常现象,进入修复迭代)
